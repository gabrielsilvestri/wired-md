# Quick guide

Shortcuts worth memorizing in wired-md.

- Ctrl+P opens the quick switcher, Ctrl+Shift+P the command palette.
- Ctrl+click in the tree opens the note in a pane beside the current one.
- Ctrl+= and Ctrl+- change the document zoom; Ctrl+0 goes back to the default.
- Ctrl+` opens the embedded terminal in the folder of the note.
- The sparkles button in the pane header sends the note to claude.
